# ROCm QA Logs

This branch contains raw test logs generated by the ROCm QA automated testing
infrastructure.

These logs correspond to the test runs reflected in the main repository’s
dashboard and badges.

## Structure

Logs are stored using the following directory layout:


### Example
```
logs/bare-gfx1151:gfx-1151:packages/amdsmi/tests/level-one/echo/output-2026-03-25-11:09:04.log
logs/bare-gfx908:gfx-908:packages/hipfft/tests/autopkgtest/execute/output-2026-03-25-11:13:22.log
```

## Naming Breakdown
```
logs/{backend:system}:packages/{source_pkg}/tests/{test}/{task}/output-{timestamp}.log
```

- **backend:system**: Execution environment and GPU target (e.g. `bare-gfx1151:gfx-1151`)
- **source_pkg**: Ubuntu source package under test (e.g. `amdsmi`, `hipfft`)
- **test**: Test suite type (e.g. `autopkgtests`, `level-one`)
- **task**: Specific test or scenario
- **timestamp**: Unique identifier for the test run

## Purpose

- Store full logs for debugging test failures
- Provide traceability for dashboard results
- Enable post-run analysis and reproducibility

## Notes

- This branch is **append-only** and updated automatically by CI
- Logs may grow large over time
- No guarantees are made about long-term retention or cleanup
